# Ancient City Sculk Tracker

Issue tracker and documentation for Ancient City Sculk Tracker by aerithsmods.

This repository does not contain the mod's source code.

## Support

Use the Issues tab to report bugs, request features, or report compatibility problems.

Please include:
- Minecraft version
- Fabric Loader version
- Fabric API version
- Mod version
- Relevant logs or crash reports
- Steps to reproduce the issue

## Downloads

Download the mod only from its official Modrinth or CurseForge page.
